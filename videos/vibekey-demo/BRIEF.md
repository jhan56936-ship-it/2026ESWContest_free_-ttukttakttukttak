## Intent

2026 임베디드SW 경진대회 자유공모 부문(팀 뚝딱뚝딱) 제출용 시연영상.
홍보영상이 아니라 **기술 문서의 영상판**이다. 심사 기준이 기술 완성도이므로
전체 175초 중 75초(43%)를 기기 내부 구조에 쓴다.

사이트가 없는 제품이라 no-capture 모드. 소재는 이 저장소의 코드·회로·문서.

## 제품

**바이브키(VibeKey)** — USB로 폰에 꽂는 물리 버튼 3개짜리 입력 기기.
스마트폰이 어려운 어르신이 복잡한 홈 화면 대신 버튼을 눌러
전화·문자·길찾기·AI 도우미를 바로 연다.

- MCU: Seeed Studio XIAO ESP32-S3
- 입력: 버튼 3개 (D0·D1·D2, INPUT_PULLUP)
- 연결: USB CDC (네이티브 USB, 0x303A:0x1001)
- 진동은 **폰이** 한다. 기기에는 진동 모터가 없다.

## 기술 (4구간에서 다룰 것)

1. GPIO 인터럽트(ISR)로 눌림 순간 포착 → 큐 → FreeRTOS 태스크 2개(코어 1 고정)
2. VKP v1 프레임: `AA │ SEQ │ TYPE │ LEN │ 데이터 │ CRC16 │ 55`
3. CRC-16/CCITT-FALSE 검증 + ACK 재전송 + SEQ 중복 제거
4. 태스크 워치독 5초 → 멈추면 자동 재시작, 재시작 원인을 폰에 보고
5. 짧게/길게 누르기 구분 → 버튼 3개로 6가지 동작

## 확인된 수치 (영상에 써도 되는 것)

- 자동 테스트 89개 (펌웨어 41 + 앱 48)
- 플래시 사용 8% (277,057 B)
- RAM 사용 6% (22,608 B)
- 부품 5종, 약 14,690원

## 절대 넣지 말 것

- **버튼 → 앱 실행 지연(ms)** : 실측 안 했음
- **프레임 오류율(%)** : 실측 안 했음
- 기기가 진동한다는 표현 (모터 없음)
- 실물 사진인 척하는 AI 생성 이미지

## Customizations

- 카운트업 수치 연출은 확인된 4개만 사용
- 4-C·4-D(프레임 조립 → 비트 손상 → 폐기 → 재전송)가 기술 하이라이트
- 1구간의 "벽"과 6구간의 "세 번"을 같은 손 클로즈업으로 수미상관
