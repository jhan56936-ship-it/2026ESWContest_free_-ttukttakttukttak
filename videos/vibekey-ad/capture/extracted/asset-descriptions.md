# 자산 목록

사이트가 없는 제품이라 웹 캡처는 하지 않았다(no-capture). 아래는 직접 만든 소재다.

## 영상 (실제 앱 화면 녹화 — 에뮬레이터, 안드로이드 14)

| 파일 | 길이 | 내용 |
|---|---|---|
| `capture/assets/demo-onboarding.mp4` | 26.8초 | 1080×2400 세로. 첫 실행 → "무엇을 자주 하시나요?"에서 전화 걸기·길 찾기·사진 보기를 고름 → 1번 Phone / 2번 Maps / 3번 Photos 로 배치된 결과 → "이대로 쓸게요" → 홈 화면 |
| `capture/assets/demo-press.mp4` | 10.1초 | 1080×2400 세로. 홈에서 1번 단추 칸을 누름 → "1번 버튼 / 지금은 'Phone'이 열려요" → "지금 눌러 보기" → 전화 앱이 실제로 열림 → 홈 복귀 |

두 녹화 모두 상태바를 데모 모드로 고정했다(9:00 · 배터리 100% · 알림 없음).

**주의** — 제미나이 API 키가 없는 상태에서 녹화해서, 결과 화면의 안내 문구가
"인터넷 없이 정했어요"로 나온다. 단추 배치 결과(1·2·3번 행)와 기능 고르기 화면은
키가 있든 없든 완전히 같다. 영상에서는 **그 두 부분만 쓰고 안내 문구 줄은 화면에 넣지 않는다.**
